# Чек-лист для saucedemo.com

## 1. Логин
### Позитивные
- standard_user входит успешно
- problem_user входит успешно
- performance_glitch_user входит успешно
- error_user входит успешно
- visual_user входит успешно
### Негативные
- Вход с пустым паролем показывает ошибку
- Вход с пустыми логином и паролем показывает ошибку
- Вход с пустым логином показывает ошибку
- Вход с логином locked_out_user показывает сообщение о блокировке
- Вход с неверным логином или паролем показывает ошибку
### UI
- Поля ввода видны и доступны
- Кнопка Login видна и доступна
- Пароль скрыт (type=password)

## Главная страница (Inventory)
### UI
- Значок корзины виден и доступен
- Значок меню виден и доступен
- Фильтр товаров виден и доступен
- Карточки товаров содержат название, описание, цену с указанием валюты и кнопку "Add to cart"

### Логика
- При нажатии на название товара происходит переход на страницу товара

- При клике на "Add to cart" кнопка меняется на "Remove"
- При клике на "Add to cart" счётчик корзины увеличивается на 1
- При клике на "Add to cart" товар появляется в корзине

- При клике на "Remove" кнопка меняется на "Add to cart"
- При клике на "Remove" счётчик корзины уменьшается на 1
- При клике на "Remove" товар удаляется из корзины

- Сортировка товаров A to Z отображает товары в алфавитном порядке
- Сортировка товаров Z to A отображает товары в обратном алфавитном порядке
- Сортировка товаров по Price (low to high) отображает товары в порядке возрастания цены
- Сортировка товаров по Price (high to low) отображает товары в порядке убывания цены

## Страница товара

### UI
- На странице есть кнопка "Back to products"
- В карточке товара присутствует фото товара
- В карточке товара присутствует название товара
- В карточке товара присутствует описание товара

- В карточке товара присутствует цена товара с указанием валюты. Цена товара - положительное число
- В карточке товара присутствует кнопка "Add to cart"

### Логика
- При клике на "Add to cart" кнопка меняется на "Remove"
- При клике на "Add to cart" счётчик корзины увеличивается на 1
- При клике на "Add to cart" товар появляется в корзине

- При клике на "Remove" кнопка меняется на "Add to cart"
- При клике на "Remove" счётчик корзины уменьшается на 1
- При клике на "Remove" товар удаляется из корзины

- Цена на странице товара совпадает с ценой в каталоге

## Корзина
### UI
- На странице корзины есть заголовок "Your Cart"
- На странице корзины есть блок со списком добавленных товаров
- На странице корзины есть кнопка "Continue Shopping"
- На странице корзины есть кнопка "Checkout"

- В карточке каждого товара в корзине есть название товара
- В карточке каждого товара в корзине есть описание товара
- В карточке каждого товара в корзине есть цена товара с указанием валюты
- В карточке каждого товара в корзине есть кнопка "Remove"

### Логика
- Нажатие на кнопку "Continue Shopping" ведет на главную страницу (Inventory)
- Нажатие на кнопку "Checkout" ведет на страницу оформления заказа (checkout-step-one.html)
- При клике на название товара происходит переход на страницу товара
- Нажатие на кнопку "Remove" удаляет товар из корзины
- При клике на "Remove" счётчик корзины уменьшается на 1
- При пустой корзине переход на /checkout-step-one.html невозможен
- Цена товара в корзине совпадает с ценой в каталоге

## Оформление заказа - Заполение формы. 
### Негативные
- Нажатие Continue с пустыми полями покажет ошибку
- Нажатие Continue только с First Name покажет ошибку
- Нажатие Continue только с Last Name покажет ошибку
- Нажатие Continue только с Zip покажет ошибку
- Ввод цифр или специальных знаков в поле First Name покажет ошибку
- Ввод цифр или специальных знаков в поле Last Name покажет ошибку
- Ввод букв или специальных знаков в поле Zip/Postal Code покажет ошибку
- Ввод более 6 знаков в поле Zip/Postal Code покажет ошибку

### UI
- На странице есть заголовок "Checkout: Your Information"
- На странице есть форма, состоящая из 3 полей: 
    - Поле для First Name
    - Поле для Last Name
    - Поле для Zip/Postal Code
- На странице есть кнопка "Cancel" 
- На странице есть кнопка "Continue"

### Логика
- Все поля обязательные для заполнения. Переход на следующую страницу оформления заказа будет невозможен, если хотя бы одно поле не заполнено.
- Кнопка "Cancel" ведет в корзину
- Кнопка "Continue" ведет на следующий этап оформления и только при условии, что все поля заполнены
- Поля правильно отображают введенные данные
- Счетчик корзины отображает число добавленных товаров

## Оформление заказа - Детали и описание заказа
### UI
- На странице есть заголовок "Checkout Overview"
- На странице есть блок со списком добавленных товаров
- На странице есть блок с деталями оплаты и доставки, а именно: 
            - Payment Information: SauceCard #31337
            - Shipping Information: Free Pony Express Delivery!
            - Price Total
                - Item total: число с указанием валюты
                - Tax: число с указанием валюты
                - Total: число с указанием валюты
- На странице есть кнопка "Cancel"   
- На странице есть кнопка "Finish"

### Логика
- Кнопка "Cancel" ведет на главную страницу (Inventory)       
- Кнопка "Finish" ведет на страницу подтверждения заказа(checkout-complete.html)
- Цена товара совпадает с ценой в каталоге
- Число Item total является суммой всех товаров в заказе.
- Tax = 8% от Item total
- Число Total является суммой Item total и Tax
- Счетчик корзины отображает число добавленных товаров
- Названия товаров в списке совпадают с названиями в корзине

## Checkout Complete
### UI
- На странице есть текст "Thank you for your order!"
- На странице есть текст "Your order has been dispatched, and will arrive just as fast as the pony can get there!"
- На странице есть кнопка "Back Home"
- На странице есть кнопка "Generate PDF order"

### Логика
- Кнопка "Back Home" ведет на главную страницу (Inventory) 
- После нажатия на кнопку "Back Home" корзина пуста
- Счетчик корзины не отображается, тк корзина пуста
- Кнопка "Generate PDF order" скачивает на устройство PDF-файл  

Указать что не проверяется дизайн страницы и ее внешний вид. тестируется только функционал и доступность
